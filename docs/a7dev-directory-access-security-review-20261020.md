The installed immutable source opens every ancestor with `O_RDONLY|O_DIRECTORY|O_NOFOLLOW`. Execute permission permits path traversal but does not satisfy a directory read open.

An independent unprivileged synthetic DAC test confirmed an execute-only directory rejects `O_RDONLY`, accepts `O_PATH`, and accepts `O_RDONLY` after adding only its read bit. An `O_PATH` code repair could retain 0710, but would require changing and readmitting immutable runtime code. The proposed 0710→0750 change supplies precisely the read bit needed by the existing admitted code. It grants directory-name visibility only to the already exclusive service group; it adds neither group write nor world access. Root ownership and child permissions remain unchanged. Current DATA ACL metadata contains only base user/group/other entries; the launcher must reject extended access ACLs to avoid unmasking other principals through chmod's ACL-mask effect.
